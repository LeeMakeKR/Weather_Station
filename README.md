# Weather_Station

기상청과 에어코리아 API를 활용해 날씨와 대기오염 정보를 수집하고 시각화하는 ESP32 기반 프로젝트입니다. ESP32-C3 개발 보드를 기본으로 합니다.

## 문서

- [개발계획서](개발계획서): 위치정보 변환 로직, Wi-Fi 설정 개선, 디스플레이 설계 및 표시 계획.
- [API 조회 가능 데이터](documents/API_조회가능데이터.md): 단기예보·중기예보·에어코리아의 조회 조건과 제공 데이터.
- [개발로그](개발로그.md): 개발 진행 기록.

## 추가 예정 기능

1. 웹페이지에서 API 키를 입력하고 설정하는 기능.
2. 웹페이지에서 사용자 위치를 설정하는 기능.
3. 시도 및 주소 정보를 저장·관리하는 데이터베이스.
4. 미세먼지 API 응답을 수신하고 처리하는 기능.
